# Batch lot state transitions

Changing the state of a medicine batch lot, for example from AVAILABLE to QUARANTINED, RELEASED or RECALLED, is a TIER_3 action. The assistant can only submit a request, which stays PENDING_APPROVAL until a pharmacist approver in the same tenant approves it. See [[SOP-STORAGE]].

> DEMO CONTENT - tenant-approved monographs must replace this note. Not a substitute for pharmacist advice.
